## Neden bu repo?

- Türkçe kaynak azlığı: çoğu writeup İngilizce.
- "Flag'i aldım" değil, **neden çalıştığını** anlatır.
- Yalnızca halka açık lab'lar (PortSwigger, TryHackMe, HTB, CTFtime arşivleri). Gerçek hedef verisi yok.

## Katkı

1. Yalnızca yasal lab/CTF içeriği.
2. Adımlar baştan sona tekrarlanabilir olmalı.
3. Flag, token, kişisel veri ve kopyalanmış içerik yok.
4. Kaynak lab linki ve zorluk seviyesi belirtilmeli.
